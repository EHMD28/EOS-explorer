# Equation of State Data

`gev/` - Contains tabulated EoSs with the energy in GeV/fm^3
`mev/` - Contains tabulated EoSs with the energy in MeV/fm^3. See below for mapping from EoS number to EoS name.

```
{
    134: 'Sly',
    2: 'DD2',
    253: 'PCP(BSK24)',
    14: 'SFHo',
    68: 'APR',
    214: 'FSU2R',
    121: 'BL (chiral)'
}
```
